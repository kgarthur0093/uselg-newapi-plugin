# uselgv0.1

NewAPI Task Plugin API v1 适配器，适用于普通 OpenAI 兼容渠道，处理 Uselg 图片、视频和音乐任务以及相应的按张、按次、按秒用量。

## 渠道配置

在 NewAPI 中新增或编辑 OpenAI 兼容渠道，填写上游 API Base URL 和 API Key。普通 OpenAI 渠道仍通过上游 `/v1/models` 同步模型；插件的任务适配会读取所选渠道的 Base URL 与密钥，并按模型协议生成图片、视频或音乐请求。

插件模型目前在 `meta.models` 中静态声明。渠道同步出的模型只有在插件模型清单中，或被映射到清单中的受支持模型后，才能进入此插件的媒体适配流程。上游新增任意模型不会自动扩大插件的受支持集合。

## 与内置 Sora 的冲突

NewAPI rc.44 内置 Sora 插件也声明普通 OpenAI 渠道类型 `1`。NewAPI 的插件路由代际不允许两个插件同时声明同一渠道类型。因此安装本插件前，必须在 NewAPI 插件管理中停用内置 `sora` 插件；这会停用通过该插件提供的 Sora 模型适配。若需要同时保留 Sora 与 uselgv0.1，需由 NewAPI 上游支持多插件共享同一渠道类型后再实现，不能仅靠当前插件索引解决。
